- 开始清理时已有大量暂存代码和结果。本轮未编辑这些文件；结束时对 693 个已有改动文件核对清理前的 SHA256，全部一致。用于核对的临时基线已移除。
- `results/result_c5_v1` 是当前运行入口使用且现有说明明确保留的结果目录；`result_c5` 的同名 JSON 内容不同，也予以保留。没有论文源文件，无法进一步认证论文引用范围。

- CIM 请求矩阵、返回样本和计时记录具有溯源价值，不能按可生成文件处理。
- `result_c5_v1/results.csv` 与 `summary/runs.csv` 内容相同，但前者是 `run.run` 明确生成的便捷导出，保留现有输出接口。

- 已有 pytest 临时目录存在权限差异，未改变权限或删除。后续测试通过限定收集目录避开它们。
